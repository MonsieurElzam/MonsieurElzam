## The instruments

Free automation scripts: dependency-free Node.js, MIT licence, for developers and entrepreneurs. Data quality, quotes and invoices, cash flow, lead scoring, backups, process analysis, security and monitoring. Each one has its own repository, its tests and, often, a step-by-step guide in English and French. Overview, guides and full archive: [monsieurelzam.com/en/scripts](https://monsieurelzam.com/en/scripts).

<details>
<summary>Open the toolbox</summary>

- [Access-log summary](https://github.com/MonsieurElzam/automation-log-summary): Traffic, status classes, busiest pages and IPs, frequent errors and peak hours ("combined" format).
- [Changelog from Git](https://github.com/MonsieurElzam/automation-git-changelog): Generates a Markdown CHANGELOG grouped by type from conventional commits (feat, fix, perf…) between two references.
- [CSV ↔ JSON converter](https://github.com/MonsieurElzam/automation-csv-json): Converts both ways; the direction is inferred from the input file's extension.
- [CSV de-duplication](https://github.com/MonsieurElzam/automation-csv-dedupe): Removes duplicates on one or more columns, ignoring case, accents and whitespace.
- [CSV diff](https://github.com/MonsieurElzam/automation-csv-diff): Added, removed and changed rows between two exports, on a key. Exit code 2 when they differ.
- [CSV profiler](https://github.com/MonsieurElzam/automation-csv-profile): Types, empty rates, distinct values and candidate keys for every column — the first reflex before any data cleanup.
- [Encrypted backup](https://github.com/MonsieurElzam/automation-encrypt-backup): Encrypts and decrypts a file with AES-256-GCM, scrypt-derived key; the passphrase comes from an environment variable.
- [Environment variables check](https://github.com/MonsieurElzam/automation-env-check): Compares .env.example with a real .env: missing, empty, example-value and extra variables. Never prints values.
- [Folder inventory](https://github.com/MonsieurElzam/automation-folder-inventory): Size by extension, largest files and duplicates found by SHA-256 — handy for auditing a workstation or a share.
- [Invoice reminders](https://github.com/MonsieurElzam/automation-invoice-reminders): Finds unpaid invoices and drafts one reminder each at day 7, 21 and 45. It sends nothing — you review before sending.
- [JSON file linter](https://github.com/MonsieurElzam/automation-json-lint): Validates every .json in a folder: errors with line and column, duplicate keys, JSONC mode for comments.
- [Outdated dependencies report](https://github.com/MonsieurElzam/automation-deps-outdated): Sorts `npm outdated` by severity (majors first) and fails CI above a threshold of major gaps.
- [Process mapper](https://github.com/MonsieurElzam/automation-process-mapper): From a list of steps: Mermaid diagram, critical path, waiting bottlenecks, efficiency and hand-offs between owners.
- [RACI matrix check](https://github.com/MonsieurElzam/automation-raci-check): Checks exactly one accountable (A) and at least one responsible (R) per task, and flags work concentrated on one person.
- [Secrets scanner](https://github.com/MonsieurElzam/automation-secrets-scan): Detects API keys, tokens and private keys left in a folder, values masked. Run it before commits or in CI.
- [Sitemap checker](https://github.com/MonsieurElzam/automation-sitemap-check): Walks a sitemap.xml (index included) and tests every URL to catch broken pages and failed redirects.
- [TLS certificate expiry](https://github.com/MonsieurElzam/automation-ssl-expiry): Days left before each certificate expires, with warning (30 d) and critical (7 d) thresholds.
- [Uptime check](https://github.com/MonsieurElzam/automation-http-check): Checks a list of URLs (status, duration, slowness threshold) and exits with code 2 if any fails.
- [Weekly sales report](https://github.com/MonsieurElzam/automation-weekly-report): Revenue, sales count, average basket and top products in Markdown, compared with the previous week.
